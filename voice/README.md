# 语音

手机上用嘴跟 agent 说话、用耳朵听它做完了什么。设置里「语音输入」「朗读」各有开关，只用一半就关掉另一半。

## 语音输入

**按住** 📎 右边的 🎤 说话（它固定在那里，不会跟着别的按钮动），输入框上方的气泡里显示录了多久，说的话边说边出字（白字是说定的句子，灰字是还在变的那句）。

- **松手**：识别完的文字放进输入框，你看过、改过再发。气泡里会写这次花了多久（识别 x 秒 · 纠错 y 秒）。
- **上滑**再松手：取消这一段。
- **右滑**再松手：直接发出去。

比手机输入法准，是因为识别时带上了这段对话：

- 设置里的「我的词表」（一行一个：产品名、人名、术语，中文也行）；
- 对话里出现过的英文词和标识符（会话标题、项目文件夹名、agent 上一条回复）；
- 豆包还会把 agent 上一条回复当上下文一起识别；
- 「纠错模型」：识别完再交给 Gerdr 里配好的一个模型，结合对话改同音字和术语。

## 朗读

- **消息旁的喇叭**：念这一条，一段一段读、正在读的那段高亮，点哪段从哪段接着读。agent 的回复默认只念最后一段（干完活的总结）。
- **输入框旁的 🎧，点一下**：念这个对话最新的回复，不用去翻消息找喇叭；再点一下停。
- **🎧 长按：开关自动朗读**（只对这台设备，开着时 🎧 是主题色）：任何一个 agent 做完一轮就念它的结论，开头报是哪个会话。几个 agent 同时跑时排队，每一轮只念一次，同一个会话只留最新那条；在等你批准 / 回答的排最前面。「叮一声，我点了再念」模式下点顶上的 ▶，蓝牙耳机 / 方向盘的「下一首」也行。
- 念的是去掉 Markdown 的文字：代码说「代码见屏幕」，链接和长路径不逐字念。

App 切到后台、锁屏时网页会被系统暂停，念不出来：放在车载支架上、Gerdr 留在前台用。

## 识别服务

设置里「识别用」二选一：

- **豆包（火山引擎）**：国内，约 1 元/小时；会把这段对话（agent 上一条回复、对话标题）当上下文一起识别，每句说完还用非流式模型复核一遍。填火山引擎控制台 → 豆包语音的 API Key（老版控制台：Access Token + App ID）。
- **微软 Azure**：每月 5 小时免费，之后约 7 元/小时；只能用词表当提示。

**纠错模型**（可选）：识别完再交给 Gerdr 里配好的一个模型（设置 → 模型），结合对话改同音字和术语，比如聊排版时把“对不起”改成“对不齐”。气泡里会显示每一步花了多久。

## 设置

「语音输入」「朗读」两个开关，关掉的那一半连按钮都不显示。各自下面只显示所选服务商的那几项；**试听**用朗读设置念一句。

要求 Gerdr 支持 `g.socket`、`g.llm`、`g.sessions.reply`、`g.audio.unlock` 和 composerAction 的 `place` / `render`；安卓 App 要放开了麦克风的版本。
