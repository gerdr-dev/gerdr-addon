# 语音

手机上用嘴跟 agent 说话、用耳朵听它做完了什么。设置里「语音输入」「朗读」各有开关，只用一半就关掉另一半。

## 语音输入

**按住** 📎 右边的 🎤（或输入框中间的「按住说话」）说话，输入框上方的气泡里显示声音波形和录了多久，说的话边说边直接进输入框。豆包每说完一句会自己复核一遍，改准的字原地替换，所以你看到的就是会发出去的。选了硅基流动 / OpenAI 兼容识别时，每停顿一下出一段字。

- **松手**：留在输入框里，看过、改过再发。
- **上滑**再松手：取消这一段。
- **右滑**再松手：直接发出去。

设置里的「松手就发送」打开后反过来：松手直接发，右滑留在输入框。中间的「按住说话」和 🎤 各有一个开关，**每台设备各自记**，默认都关。比如手机上只开中间那个：输入框空着时按中间说一句就发出去，按 🎤 说的留在输入框里接着改；电脑上没有中间那个，🎤 关着就是松手进输入框。

**电脑上用键盘**：按住**右 Option**（Windows 上是**右 Alt**）说话，右手拇指一放就是。松开后文字**留在输入框里不发送**，看一眼按回车再发；按住时按 **Esc** 取消。说进的是光标所在的输入框，没有就是当前会话的。要单独按住一小会儿（0.2 秒）才开始，所以 ⌥← 这类组合键照常用。换键在插件设置的「键盘按住说话」或设置 → 快捷键 →「扩展」里，两处是同一个：点 + 按下组合键，或单独按一下某个修饰键（左右分开）；删掉键就是不用。

比手机输入法准，是因为识别时带上了这段对话：

- 设置里的「我的词表」（一行一个：产品名、人名、术语，中文也行）；
- 对话里出现过的英文词和标识符（会话标题、项目文件夹名、agent 上一条回复）；
- 豆包还会把 agent 上一条回复当上下文一起识别；
- 「纠错模型」（可选，一般用不上）：边说边纠错，每说完一句就交给 Gerdr 里配好的一个模型，结合对话改同音字和术语，改好的直接替换在输入框里。你看到的就是会发出去的，直接发也不用猜。

## 朗读

- **消息旁的喇叭**：念这一条，一段一段读、正在读的那段高亮，点哪段从哪段接着读。agent 的回复默认只念最后一段（干完活的总结）。
- **输入框旁的 🔊，点一下**：念这个对话最新的回复，不用去翻消息找那条的 🔊；再点一下停。agent 还在答（你刚问完）时，点了就等它答完再念这次的回答，🔊 会闪着表示在等，再点一下取消。
- **🔊 长按：开关自动朗读**（只对这台设备，开着时 🔊 是主题色）：任何一个 agent 做完一轮就念它的结论，开头报是哪个会话。几个 agent 同时跑时排队，每一轮只念一次，同一个会话只留最新那条；在等你批准 / 回答的排最前面。「叮一声，我点了再念」模式下点顶上的 ▶，蓝牙耳机 / 方向盘的「下一首」也行。
- 念的是去掉 Markdown 的文字：代码说「代码见屏幕」，链接和长路径不逐字念。

App 切到后台、锁屏时网页会被系统暂停，念不出来：放在车载支架上、Gerdr 留在前台用。

## 识别服务

设置里「识别用」二选一：

- **豆包（默认）**：流式，字随说随出，见下面。
- **硅基流动 / OpenAI 兼容**：任何提供 OpenAI 那套 `/audio/transcriptions` 接口的服务。硅基流动默认用 `FunAudioLLM/SenseVoiceSmall`，免费，填个 API Key 就能用；OpenAI 默认 `gpt-4o-mini-transcribe`；「其他」可以接 Groq、本地 whisper 服务等，填接口地址（本地服务不要 Key 可以留空）。这类接口只收整段音频，所以说话时每停顿一下（约 0.6 秒），就把那一段送去识别，字比豆包晚一个停顿出来；很长不停顿的话每 25 秒也会切一次。OpenAI 和「其他」会把「我的词表」和对话里的英文词当提示一起发过去，硅基流动的接口不收提示。

**豆包（火山引擎）**用的是流式语音识别模型 2.0：国内，约 1 元/小时；会把这段对话（agent 上一条回复、对话标题）当上下文一起识别，每句说完还用非流式模型复核一遍。在火山引擎控制台 → 豆包语音 → 语音识别里开通「流式语音识别」（不是录音文件识别），填 API Key（老版控制台：Access Token + App ID）。

以前也能选微软 Azure，但它的流式结果太糙，要靠松手后再整段重识别补救，而那会换掉你说话时看到的字，就去掉了。Azure 现在只用来朗读。

**纠错模型**（可选）：每说完一句交给 Gerdr 里配好的一个模型（设置 → 模型），结合对话改同音字和术语，比如聊排版时把“对不起”改成“对不齐”。开着时松手后会等最后一句纠完，气泡里显示花了多久；不开就没有这一步。

## 朗读服务

- **豆包（火山引擎，默认）**：语音合成模型 2.0，和识别用同一个 Key（控制台里语音合成要单独开通）。一段话约 2 秒合成好，可选音色和语速。
- **小米 MiMo**、**微软 Azure**：各自填自己的 Key。
- **硅基流动 / OpenAI 兼容**：任何提供 `/audio/speech` 接口的服务，和识别共用「服务商 / API Key / 接口地址」。硅基流动默认 `FunAudioLLM/CosyVoice2-0.5B`，有 8 个预置音色（anna、claire、alex……），换朗读模型后音色跟着换；自己上传的克隆音色选「自定义…」填 `speech:…`。OpenAI 默认 `gpt-4o-mini-tts`，音色 coral。

## 设置

「语音输入」「朗读」两个开关，关掉的那一半连按钮都不显示。各自下面只显示所选服务商的那几项；**试听**用朗读设置念一句。

要求 Gerdr 支持 `g.socket`、按住型命令（`g.command` 的 `release`、`g.ui.Shortcut`，键盘按住说话要它）、`g.llm`、`g.sessions.reply`、`g.audio.unlock` 和 composerAction 的 `place` / `render`；安卓 App 要放开了麦克风的版本。桌面 App 要 0.2.50 之后的版本（gerdr f48ecc4 起把 `http://gerdr` 当安全页面，之前的版本页面里没有麦克风接口，按 🎤 会提示用不了）。
